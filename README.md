# 생기부 점검 허브

NEIS에서 내려받은 학생부 엑셀 파일을 브라우저에서 바로 점검하는 도구입니다.

- **교과세특 점검**: 여러 과목 파일을 학생별·과목별로 모아 점검합니다.
- **창체·행특 점검**: 동아리, 진로, 자율, 행동특성 및 종합의견을 유형별로 점검합니다.
- **쉬운 결과 확인**: 확인할 표현을 색으로 표시하고 바이트 수를 함께 보여줍니다.
- **수정 모드**: 고칠 문장을 화면에서 바로 다듬고, NEIS에 올릴 수정본 엑셀을 받습니다.
- **결과 저장**: 전체 요약 엑셀, 과목별 ZIP, 이슈 복사를 지원합니다.
- **브라우저 안에서 처리**: 올린 학생 데이터는 서버로 전송하지 않습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. **교과세특** 또는 **창체·행특**을 선택합니다.
3. NEIS에서 내려받은 엑셀 파일을 끌어다 놓거나 선택합니다.
4. **전체 점검하기**를 눌러 표시된 내용을 확인합니다.
5. 문장을 고치려면 **수정 모드**를 누릅니다. (아래 참고)
6. 필요한 경우 점검 결과를 엑셀이나 ZIP 파일로 내려받습니다.

> 이 도구의 결과는 문장을 검토하기 위한 참고 자료입니다. 최종 기재 내용은 해당 연도의 학교생활기록부 기재요령과 학교 기준을 함께 확인해 주세요.

## 수정 모드

점검 결과 화면 위쪽의 **수정 모드** 버튼을 누르면 학생을 한 명씩 넘겨보며 문장을 다듬는 화면이 열립니다. 다 고친 뒤에는 NEIS에 그대로 올릴 수 있는 수정본 엑셀을 받습니다.

### 화면 보는 법

화면은 세 칸으로 나뉩니다.

- **왼쪽**: 학생 목록입니다. 끝낸 학생에는 체크 표시가 붙고 위쪽에 `3/35 완료`처럼 진행 상황이 나옵니다.
- **가운데**: 원문 → 수정안 → 결과 미리보기 순서로 보여줍니다. 체크를 켜고 끌 때마다 미리보기가 바로 바뀝니다.
- **오른쪽**: 바이트 수와 문장별 길이입니다. 문장 옆 버튼을 누르면 그 문장을 빼고 몇 바이트가 되는지 확인할 수 있습니다.

### 수정안의 세 가지 종류

| 표시 | 뜻 | 예 |
|---|---|---|
| 체크되어 있음 | 바꿔도 문제없는 것이라 미리 켜 둡니다 | `정리했고` → `정리하고` |
| 후보 중 고르기 | 문맥에 따라 달라져서 선생님이 고릅니다 | `유튜브` → `동영상 플랫폼` 또는 `영상 창작자` |
| 회색으로 표시만 | 자동으로 바꾸면 위험해 위치만 알려줍니다 | `학생은`, 가운뎃점 `·` |

미리 켜져 있어도 **미리보기를 보고 확정**하시면 됩니다. 마음에 들지 않으면 체크를 끄면 원래 문장으로 돌아갑니다.

### 빠르게 넘기기

키보드로도 넘길 수 있습니다.

| 키 | 하는 일 |
|---|---|
| `J` / `K` | 다음 / 이전 학생 |
| `스페이스` | 완료 표시하고 다음 학생 |
| `C` | 고친 문장 복사 |
| `Esc` | 수정 모드 닫기 |

### 수정본 내려받기

왼쪽 아래 **수정본 내려받기**를 누르면 원래 파일과 같은 양식으로 문장만 바뀐 엑셀이 만들어집니다. 이 파일을 NEIS에 올리면 한 번에 반영됩니다.

- 원본 파일은 그대로 두고 새 파일(`파일이름_수정본.xlsx`)로 받습니다.
- 파일을 여러 개 올렸으면 ZIP으로 묶어 받습니다.
- 아직 확인하지 않은 학생이 있으면 물어봅니다. 확인한 학생만 받을지, 전체를 받을지 고르세요.

작업하던 내용은 브라우저에 저장되어 있어서, 창을 닫았다가 같은 파일을 다시 올려도 이어서 할 수 있습니다.

### 수정본을 만들 수 없는 경우

아래 두 가지는 화면에 보이는 문장과 실제 파일에 저장된 내용이 달라질 수 있어 수정본 만들기를 막아 두었습니다. 이때는 **고친 문장 복사**를 눌러 NEIS에 직접 붙여넣어 주세요.

- NEIS **인쇄 출력** 형식으로 받은 파일 (되돌려 올릴 수 있는 양식이 아닙니다)
- 한 학생의 글이 여러 줄에 나뉘어 기록된 **진로활동 묶음** 형식

막힌 이유는 화면에도 함께 표시됩니다.

> 수정본을 올리기 전에 NEIS에서 내용을 한 번 더 확인해 주세요. 바뀐 문장이 기재요령에 맞는지는 결국 선생님의 판단입니다.

## 실행 방법

별도 설치나 서버가 필요 없는 정적 웹사이트입니다. 저장소를 내려받은 뒤 `index.html`을 더블클릭하면 실행할 수 있습니다.

브라우저 보안 설정 때문에 일부 기능이 동작하지 않으면, 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`에 접속하세요.

```bash
python3 -m http.server 8000
```

## 지원 파일

- 엑셀 파일: `.xlsx`, `.xls`
- 교과세특: 여러 과목 파일 동시 선택 가능
- 창체·행특: 동아리활동, 진로활동, 자율활동, 행동특성 및 종합의견

## 개인정보 보호

엑셀 읽기, 문장 점검, 결과 파일 만들기는 모두 사용자의 브라우저 안에서 이루어집니다. 업로드한 학생 정보는 별도 서버로 보내거나 저장하지 않습니다.

공용 컴퓨터에서는 사용을 마친 뒤 내려받은 결과 파일을 직접 삭제해 주세요.

## 주요 파일

```text
index.html                  시작 화면
subject.html                교과세특 점검 화면
career.html                 창체·행특 점검 화면
assets/js/                  엑셀 처리와 점검 규칙, 수정 모드
assets/css/                 화면 디자인
tests/                      점검 규칙 검증 (node tests/suggest.test.js)
CORE-LOGIC.md               점검 로직 상세 설명
DESIGN.md                   디자인 기준
```

## 기술 구성

HTML, CSS, JavaScript만 사용하며 별도의 백엔드는 없습니다. 엑셀 처리는 SheetJS, ZIP 생성은 JSZip을 사용합니다.
