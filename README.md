# 생기부 점검 허브

NEIS에서 내려받은 학생부 엑셀 파일을 브라우저에서 바로 점검하는 도구입니다.

- **교과세특 점검**: 여러 과목 파일을 학생별·과목별로 모아 점검합니다.
- **창체·행특 점검**: 동아리, 진로, 자율, 행동특성 및 종합의견을 유형별로 점검합니다.
- **쉬운 결과 확인**: 확인할 표현을 색으로 표시하고 바이트 수를 함께 보여줍니다.
- **결과 저장**: 전체 요약 엑셀, 과목별 ZIP, 이슈 복사를 지원합니다.
- **브라우저 안에서 처리**: 올린 학생 데이터는 서버로 전송하지 않습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. **교과세특** 또는 **창체·행특**을 선택합니다.
3. NEIS에서 내려받은 엑셀 파일을 끌어다 놓거나 선택합니다.
4. **전체 점검하기**를 눌러 표시된 내용을 확인합니다.
5. 필요한 경우 점검 결과를 엑셀이나 ZIP 파일로 내려받습니다.

> 이 도구의 결과는 문장을 검토하기 위한 참고 자료입니다. 최종 기재 내용은 해당 연도의 학교생활기록부 기재요령과 학교 기준을 함께 확인해 주세요.

## 실행 방법

별도 설치나 서버가 필요 없는 정적 웹사이트입니다. 저장소를 내려받은 뒤 `index.html`을 더블클릭하면 실행할 수 있습니다.

브라우저 보안 설정 때문에 일부 기능이 동작하지 않으면, 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`에 접속하세요.

```bash
python3 -m http.server 8000
```

## 지원 파일

- 엑셀 파일: `.xlsx`, `.xls`
- 교과세특: 여러 과목 파일 동시 선택 가능
- 창체·행특: 동아리활동, 진로활동, 자율활동, 행동특성 및 종합의견

## 개인정보 보호

엑셀 읽기, 문장 점검, 결과 파일 만들기는 모두 사용자의 브라우저 안에서 이루어집니다. 업로드한 학생 정보는 별도 서버로 보내거나 저장하지 않습니다.

공용 컴퓨터에서는 사용을 마친 뒤 내려받은 결과 파일을 직접 삭제해 주세요.

## 주요 파일

```text
index.html                  시작 화면
subject.html                교과세특 점검 화면
career.html                 창체·행특 점검 화면
assets/js/                  엑셀 처리와 점검 규칙
assets/css/                 화면 디자인
CORE-LOGIC.md               점검 로직 상세 설명
DESIGN.md                   디자인 기준
```

## 기술 구성

HTML, CSS, JavaScript만 사용하며 별도의 백엔드는 없습니다. 엑셀 처리는 SheetJS, ZIP 생성은 JSZip을 사용합니다.
